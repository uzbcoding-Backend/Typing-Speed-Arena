# Typing-Speed-Arena

An interactive typing practice app.

## Features
Practice short prompts and view estimated typing speed and accuracy.

- Responsive dark-blue design
- Vanilla HTML, CSS and JavaScript
- No dependencies or installation

## Getting started
Open `index.html` in your web browser.

## Project structure
- `index.html`: UI markup
- `style.css`: responsive styling
- `app.js`: interactive behavior
- `README.md`: documentation

## GitHub Pages
Go to **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)**.
